# Documentation Guidelines

- JSDoc comments for CLI tools are helpful but not required
- Use block comments to delineate major sections
- Keep README.md updated with new features
- Keep AGENTS.md updated when referred file names or conventions are updated

## Related Files

- `AGENTS.md` - Agent-specific instructions (includes `@CLAUDE.md`)
- `CLAUDE.md` - This file (table of contents + summary)
- `docs/knowledge/` - Detailed topic-specific knowledge files
